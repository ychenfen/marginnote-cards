# 卡片格式规范

## 层级
```
#      根节点（整份材料的名字）
##     章 / 大板块
###    簇（按方法聚类的一组卡片）
####   单张卡片
```

正文跟在标题下，**最后单起一行**写回源锚点 `[block: b_页_序]`。

## 单卡模板

```markdown
#### 提问式标题　★来源标记
题：$\lim\limits_{x\to0}\dfrac{\cdots}{\cdots}$
- 第一步：……
- ⚠️ 关键转折：……
- ⟹ 结论

⚠️ **错因**：一句话说清为什么会错。
💡 **模板**：可迁移的判据或口诀。
[block: b_8_0]
```

要点：
- **标题必须是问句**，正文折叠后只看标题就能自测
- `★` 后面标来源（如 `★选(9) C`、`★填(4) P ≤ 2`），方便回原书核对
- `⚠️` 只标**真陷阱**（会导致错答的那一步），不要滥用
- `💡` 标**可迁移的判据**，不是复述结论
- 一张卡只讲一件事；超过 15 行就拆

## 簇（按方法聚类）

不要按题号顺序排。把「用同一招解决的题」放进同一个簇：

```markdown
### 簇 3-J｜积分计算的七种方法（解 1–8）
#### 方法一：分母 x 次数高 ⟹ 倒代换 x=1/t　★解 1(III)
#### 方法二：根号里是一次式 ⟹ 整个根号设为 t　★解 2(I)、4(V)
...
```

多个小题共用一招时，用表格横向对照比逐题展开更省、更好记。

## 章尾两张固定卡

**【必背数字】** —— 两列表格，左边"结论名"右边"内容"，纯查表用
**【解题路线】** —— 带编号的决策流程，"看到 X ⟹ 用 Y"

## 全局索引（放在根节点下）

- **诊断**：错误率表（按比率排序，不是按绝对数量）+ 题型分布信号
- **跨章串联**：把反复出现的主线列出来，每条链到代表卡片。这是"串起思路"的落点

## 卡片互链

`[[另一张卡的标题]]`，导回后成为可点击的卡片链接。
⚠️ 只能链到**本文件里出现过的**标题，且标题必须唯一。validate.py 会查断链和重名。
